Don't Want to Miss a Ball with OpenCVE

Posted Aug 24, 2026
By Lee, Chien-Pang
24 min read

A new Slack channel was created — the “Security” channel — meant to cover all sorts of security topics: CVEs, hacker news, disclosures with a high CVSS score, and so on. Team members started feeding the channel with whatever they’d learned, whether from personal subscriptions, RSS feeds, or just stumbling across it in the news; customer feedback played a role too. Over time, I couldn’t help but wonder whether critical security issues were slipping through — issues our incident-reporting channel had actually missed. The odds are high, since human input is subject to all sorts of factors. What I needed was an automated, systematic way to make sure we don’t drop the ball. That’s not to say channel members are getting kicked out — customer feedback still matters for prioritization, and the banter keeps the team’s vibe alive.

OpenCVE stood out as a good candidate, both for its popularity and its open-source nature. Not only does it offer a hosted service, but — more importantly — it gives me the freedom to build a self-hosted instance right into our own CI pipelines. The goal is to automate setting up an OpenCVE service from the ground up, so the whole thing can be rebuilt or ported elsewhere with ease. Once it’s up and running, the Grype-scanned vulnerability report from every build will automatically filter out the critical findings and subscribe to them on OpenCVE, which will then notify the security channel whenever there’s news about those subscribed packages.

Let’s get started with my favorite build tool: Makefile.

# ── OpenCVE Environment Config ────────────────────────────────────────────────
OPENCVE_REPO         := https://github.com/opencve/opencve.git
OPENCVE_DIR          := /tmp/opencve
OPENCVE_HTTP_PORT    := 8090
OPENCVE_AIRFLOW_PORT := 8091

# Base URL Airflow's Slack/email notifier builds CVE links from
# (scheduler/airflow.cfg [opencve] web_base_url). Upstream ships this as the
# literal placeholder "<your_listening_ip or fqdn>" and never fills it in,
# which breaks Slack's mrkdwn link parsing (the raw "<...|...>" shows up
# unrendered in the channel instead of a link). Override on the command line
# if this host's IP isn't the one people should click through to.
OPENCVE_WEB_BASE_URL ?= http://$(shell hostname -I | awk '{print $$1}'):$(OPENCVE_HTTP_PORT)

OPENCVE_LATEST_VERSION := $(shell git ls-remote --tags $(OPENCVE_REPO) | awk -F'/' '{print $$3}' | grep -E '^v?[0-9]' | sort -V | tail -1)
OPENCVE_INSTALLED_SRC := $(firstword $(wildcard $(OPENCVE_DIR)/opencve-*))
ifneq ($(OPENCVE_INSTALLED_SRC),)
OPENCVE_VERSION := v$(patsubst opencve-%,%,$(notdir $(OPENCVE_INSTALLED_SRC)))
else
OPENCVE_VERSION := $(OPENCVE_LATEST_VERSION)
endif
OPENCVE_SRC     := $(OPENCVE_DIR)/opencve-$(patsubst v%,%,$(OPENCVE_VERSION))
OPENCVE_RUNNING := $(shell docker inspect -f '' opencve-webserver-1 2>/dev/null)

OPENCVE_ADMIN_USER  := leechienpang
OPENCVE_ADMIN_EMAIL := lee.chienpang@gmail.com
OPENCVE_ADMIN_PASS  ?= 2026-08-24

OPENCVE_KB_DIR              := /home/airflow/repositories
OPENCVE_KB_IMPORTED_MARKER  := $(OPENCVE_SRC)/docker/.opencve_kb_imported
OPENCVE_SECRET_KEY_MARKER   := $(OPENCVE_SRC)/docker/.opencve_secret_key_set

OPENCVE_MK_DIR             := $(abspath $(dir $(lastword $(MAKEFILE_LIST))))/
OPENCVE_ORG_NAME           := MYORG
OPENCVE_PROJECT_NAME       := MYPROJ
OPENCVE_SUBSCRIBED_VENDORS := mariadb

.PHONY: help
help::
	@echo "opencve                       Fetch latest OpenCVE release, prepare and start it (fully populated) on port $(OPENCVE_HTTP_PORT)"
	@echo "opencve-version               Print the latest OpenCVE release tag"
	@echo "opencve-airflow-connections   (Re)set the Airflow<->Postgres/Redis connections (idempotent)"
	@echo "opencve-clone-kb              (Re)clone the OpenCVE KB source repos (resumable, skips ones already present)"
	@echo "opencve-import-kb             Bulk-import CVEs/vendors/products into the DB (first run only, ~10-30 min)"
	@echo "opencve-unpause-dag           Unpause the Airflow opencve DAG (hourly incremental sync)"
	@echo "opencve-subscribe-vendors     Ensure org '$(OPENCVE_ORG_NAME)' / project '$(OPENCVE_PROJECT_NAME)' subscribe to: $(OPENCVE_SUBSCRIBED_VENDORS)"
	@echo "opencve-unsubscribe-all       Clear all vendor/product subscriptions for the project (reset to empty)"
	@echo "grype-crit                    List Critical findings in a vuln.json, caches them for opencve-subscribe (VULN_JSON=...)"
	@echo "grype-high                    List High findings in a vuln.json, caches them for opencve-subscribe (VULN_JSON=...)"
	@echo "opencve-subscribe             Subscribe vendors/products from the last grype-crit and/or grype-high run(s)"
	@echo "opencve-superuser             (Re)create the OpenCVE admin user $(OPENCVE_ADMIN_USER)"
	@echo "opencve-rm                    Stop OpenCVE containers (volumes preserved)"
	@echo "opencve-clean                 Stop containers, remove volumes and downloaded source"

.PHONY: opencve-version
opencve-version:
	@echo "==> Latest OpenCVE release: $(OPENCVE_LATEST_VERSION)"
	@[ -z "$(OPENCVE_INSTALLED_SRC)" ] || echo "==> Currently installed: $(OPENCVE_VERSION) ($(OPENCVE_SRC))"

# ── Fetch, Prepare & Start ─────────────────────────────────────────────────────
.PHONY: opencve
opencve: opencve-version
	@mkdir -p $(OPENCVE_DIR)
	@test -d $(OPENCVE_SRC)/.git || (rm -rf $(OPENCVE_SRC) && git clone --depth 1 --branch $(OPENCVE_VERSION) $(OPENCVE_REPO) $(OPENCVE_SRC))
	$(Q)cd $(OPENCVE_SRC)/docker && ./install.sh -r $(OPENCVE_VERSION) prepare
	$(Q)cd $(OPENCVE_SRC)/docker && sed -i.bak -e "s/^OPENCVE_PORT=.*/OPENCVE_PORT=$(OPENCVE_HTTP_PORT)/" -e "s/^AIRFLOW_WEBSERVER_PORT=.*/AIRFLOW_WEBSERVER_PORT=$(OPENCVE_AIRFLOW_PORT)/" .env
	$(Q)rm -f $(OPENCVE_SRC)/docker/.env.bak
	$(Q)cd $(OPENCVE_SRC)/docker && sed -i.bak -e 's/Host $$host;/Host $$http_host;/' conf/opencve.conf.template
	$(Q)rm -f $(OPENCVE_SRC)/docker/conf/opencve.conf.template.bak
	$(Q)sed -i.bak -e "s|^web_base_url = .*|web_base_url = $(OPENCVE_WEB_BASE_URL)|" $(OPENCVE_SRC)/scheduler/airflow.cfg
	$(Q)rm -f $(OPENCVE_SRC)/scheduler/airflow.cfg.bak
	$(Q)cd $(OPENCVE_SRC)/docker && ./install.sh docker-up
	$(Q)$(MAKE) opencve-airflow-connections
	@test -f $(OPENCVE_SECRET_KEY_MARKER) || ( \
		cd $(OPENCVE_SRC)/docker && \
		./install.sh init-secret-key && \
		docker compose restart webserver && \
		touch $(OPENCVE_SECRET_KEY_MARKER) \
	)
	$(Q)$(MAKE) opencve-clone-kb
	$(Q)$(MAKE) opencve-import-kb
	@[ "$(OPENCVE_RUNNING)" = "true" ] || (cd $(OPENCVE_SRC)/docker && docker compose exec -T -e DJANGO_SUPERUSER_USERNAME=$(OPENCVE_ADMIN_USER) -e DJANGO_SUPERUSER_EMAIL=$(OPENCVE_ADMIN_EMAIL) -e DJANGO_SUPERUSER_PASSWORD=$(OPENCVE_ADMIN_PASS) webserver python manage.py createsuperuser --noinput || true)
	@[ "$(OPENCVE_RUNNING)" = "true" ] || (cd $(OPENCVE_SRC)/docker && docker compose exec -T postgres psql -U opencve -d opencve -c "INSERT INTO account_emailaddress(email, verified, \"primary\", user_id) SELECT email, 1::bool, 1::bool, id FROM opencve_users WHERE username='$(OPENCVE_ADMIN_USER)' ON CONFLICT (user_id, email) DO NOTHING;")
	$(Q)$(MAKE) opencve-unpause-dag
	$(Q)$(MAKE) opencve-subscribe-vendors
	@[ "$(OPENCVE_RUNNING)" = "true" ] && echo "==> OpenCVE stack already running (skipped re-init)" || true
	@echo "==> OpenCVE web UI: http://localhost:$(OPENCVE_HTTP_PORT)"
	@echo "==> Airflow UI:     http://localhost:$(OPENCVE_AIRFLOW_PORT) (airflow/airflow)"
	@echo "==> Admin login: $(OPENCVE_ADMIN_USER) / $(OPENCVE_ADMIN_PASS)"
	@echo "==> Org '$(OPENCVE_ORG_NAME)' / project '$(OPENCVE_PROJECT_NAME)' subscribed to: $(OPENCVE_SUBSCRIBED_VENDORS)"
	@echo "==> Notification links (Slack/email) point to: $(OPENCVE_WEB_BASE_URL)"

# Upstream install.sh's set-airflow-connections calls "airflow connections add"
# unconditionally, which fails if the connection already exists (e.g. after
# "opencve-rm" + "make opencve" — volumes persist, so the Airflow metadata DB
# still has it). Delete-then-add makes this idempotent across stop/start cycles.
.PHONY: opencve-airflow-connections
opencve-airflow-connections:
	@echo "==> Ensuring Airflow connections (idempotent)"
	$(Q)cd $(OPENCVE_SRC)/docker && \
		export $$(grep -v '^#' .env | grep -E '^POSTGRES' | tr '\n' ' ') && \
		(docker compose exec -T airflow-scheduler airflow connections delete opencve_postgres >/dev/null 2>&1 || true) && \
		docker compose exec -T airflow-scheduler airflow connections add opencve_postgres --conn-uri "postgres://$$POSTGRES_USER:$$POSTGRES_PASSWORD@postgres:5432/opencve" && \
		(docker compose exec -T airflow-scheduler airflow connections delete opencve_redis >/dev/null 2>&1 || true) && \
		docker compose exec -T airflow-scheduler airflow connections add opencve_redis --conn-uri "redis://redis:6379" --conn-extra '{"db": 3}'

# ── KB Repositories: clone, bulk import, enable incremental sync ────────────────
# Mirrors upstream install.sh's clone-repositories / import-opencve-kb / start-opencve-dag,
# but each step is idempotent/resumable so re-running "make opencve" always converges
# to a fully populated, working service regardless of prior partial state.
.PHONY: opencve-clone-kb
opencve-clone-kb:
	@echo "==> Cloning OpenCVE KB repositories (skips ones already present; cvelistV5 is large)"
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T airflow-scheduler sh -c 'test -d $(OPENCVE_KB_DIR)/opencve-kb/.git || git clone https://github.com/opencve/opencve-kb.git $(OPENCVE_KB_DIR)/opencve-kb'
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T airflow-scheduler sh -c 'test -d $(OPENCVE_KB_DIR)/opencve-nvd/.git || git clone https://github.com/opencve/opencve-nvd.git $(OPENCVE_KB_DIR)/opencve-nvd'
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T airflow-scheduler sh -c 'test -d $(OPENCVE_KB_DIR)/opencve-redhat/.git || git clone https://github.com/opencve/opencve-redhat.git $(OPENCVE_KB_DIR)/opencve-redhat'
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T airflow-scheduler sh -c 'test -d $(OPENCVE_KB_DIR)/cvelistV5/.git || git clone https://github.com/CVEProject/cvelistV5.git $(OPENCVE_KB_DIR)/cvelistV5'
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T airflow-scheduler sh -c 'test -d $(OPENCVE_KB_DIR)/vulnrichment/.git || git clone https://github.com/cisagov/vulnrichment.git $(OPENCVE_KB_DIR)/vulnrichment'
	@echo "==> KB repositories ready"

.PHONY: opencve-import-kb
opencve-import-kb:
	@test -f $(OPENCVE_KB_IMPORTED_MARKER) && echo "==> CVE data already imported (skipped; rm $(OPENCVE_KB_IMPORTED_MARKER) to force a re-import)" || ( \
		echo "==> Importing CVEs/vendors/products into the database (first run only, ~10-30 min)..." && \
		cd $(OPENCVE_SRC)/docker && docker compose exec -T webserver python manage.py import_cves && \
		touch $(OPENCVE_KB_IMPORTED_MARKER) && \
		echo "==> CVE import complete" \
	)

.PHONY: opencve-unpause-dag
opencve-unpause-dag:
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T airflow-scheduler airflow dags unpause opencve
	@echo "==> OpenCVE Airflow DAG unpaused (hourly incremental sync)"

# Ensures the org/project exist and subscribe to OPENCVE_SUBSCRIBED_VENDORS.
# Idempotent (get_or_create + set union), safe to run on every "make opencve".
# The vendors REST API is read-only (no create/update), so this goes through
# manage.py shell/the ORM instead, same as install.sh's own one-off admin steps.
.PHONY: opencve-subscribe-vendors
opencve-subscribe-vendors:
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T \
		-e OPENCVE_SUBSCRIBE_USER=$(OPENCVE_ADMIN_USER) \
		-e OPENCVE_SUBSCRIBE_ORG=$(OPENCVE_ORG_NAME) \
		-e OPENCVE_SUBSCRIBE_PROJECT=$(OPENCVE_PROJECT_NAME) \
		-e OPENCVE_SUBSCRIBE_VENDORS="$(OPENCVE_SUBSCRIBED_VENDORS)" \
		webserver python manage.py shell < $(OPENCVE_MK_DIR)opencve_subscribe.py

# Resets the project's subscriptions back to empty (vendors and products).
# Useful to clear out over-broad subscriptions before re-running a corrected
# subscribe target, or just to start clean. Not run automatically by anything.
.PHONY: opencve-unsubscribe-all
opencve-unsubscribe-all:
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T \
		-e OPENCVE_SUBSCRIBE_ORG=$(OPENCVE_ORG_NAME) \
		-e OPENCVE_SUBSCRIBE_PROJECT=$(OPENCVE_PROJECT_NAME) \
		webserver python manage.py shell < $(OPENCVE_MK_DIR)opencve_unsubscribe_all.py

# Reads a Syft/Grype vuln.json report (e.g. .../ship/CUBE_*_vuln.json) and
# lists every finding of one severity level (CVE/GHSA/GO id, fix state,
# affected package(s)). As a side effect, caches the CVE -> package-names
# mapping to a temp file so opencve-subscribe can reuse it without
# re-parsing the whole (often 100+MB) vuln.json again.
# The listing script itself lives in ../grype (shared with the standalone
# "make -C triangle/grype" targets); this just wires it to the
# opencve-subscribe cache files.
# Usage: make grype-crit VULN_JSON=/path/to/vuln.json
#        make grype-high VULN_JSON=/path/to/vuln.json
VULN_JSON           ?=
# Tagged with the invoking user's uid -- see the same fix in ../grype/grype.mk
# for why (a root-owned cache from manual testing otherwise blocks a Jenkins
# job, which runs as a non-root user, from overwriting the same /tmp path).
OPENCVE_TMP_TAG             := $(shell id -u)
OPENCVE_GRYPE_CRIT_FINDINGS := /tmp/opencve_grype_findings_critical_$(OPENCVE_TMP_TAG).json
OPENCVE_GRYPE_HIGH_FINDINGS := /tmp/opencve_grype_findings_high_$(OPENCVE_TMP_TAG).json
OPENCVE_GRYPE_LIST_PY       := $(OPENCVE_MK_DIR)../grype/grype_list.py

.PHONY: grype-crit
grype-crit:
	@test -n "$(VULN_JSON)" || (echo "==> ERROR: pass VULN_JSON=/path/to/*_vuln.json"; exit 1)
	@test -f "$(VULN_JSON)" || (echo "==> ERROR: file not found: $(VULN_JSON)"; exit 1)
	$(Q)python3 $(OPENCVE_GRYPE_LIST_PY) $(VULN_JSON) Critical $(OPENCVE_GRYPE_CRIT_FINDINGS)

.PHONY: grype-high
grype-high:
	@test -n "$(VULN_JSON)" || (echo "==> ERROR: pass VULN_JSON=/path/to/*_vuln.json"; exit 1)
	@test -f "$(VULN_JSON)" || (echo "==> ERROR: file not found: $(VULN_JSON)"; exit 1)
	$(Q)python3 $(OPENCVE_GRYPE_LIST_PY) $(VULN_JSON) High $(OPENCVE_GRYPE_HIGH_FINDINGS)

# Subscribes vendor/product entries for whatever grype-crit/grype-high cached
# (either or both — run one or both right before this) to the OpenCVE
# project, but only ones matching the actual scanned package name
# (best-effort token match), not a CVE's full vendors list (which NVD/MITRE
# often tags with many unrelated downstream vendors sharing the same
# underlying vulnerable component). CVE IDs not yet present in OpenCVE's
# own DB are reported, not silently dropped.
# Usage: make grype-crit opencve-subscribe VULN_JSON=/path/to/vuln.json          (Critical only)
#        make grype-crit grype-high opencve-subscribe VULN_JSON=/path/to/vuln.json (Critical + High)
.PHONY: opencve-subscribe
opencve-subscribe:
	@test -f "$(OPENCVE_GRYPE_CRIT_FINDINGS)" -o -f "$(OPENCVE_GRYPE_HIGH_FINDINGS)" || (echo "==> ERROR: run 'make grype-crit' and/or 'make grype-high' first (VULN_JSON=...)"; exit 1)
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T \
		-e OPENCVE_SUBSCRIBE_ORG=$(OPENCVE_ORG_NAME) \
		-e OPENCVE_SUBSCRIBE_PROJECT=$(OPENCVE_PROJECT_NAME) \
		-e OPENCVE_GRYPE_CRIT_FINDINGS="$$([ -f $(OPENCVE_GRYPE_CRIT_FINDINGS) ] && cat $(OPENCVE_GRYPE_CRIT_FINDINGS) || echo '{}')" \
		-e OPENCVE_GRYPE_HIGH_FINDINGS="$$([ -f $(OPENCVE_GRYPE_HIGH_FINDINGS) ] && cat $(OPENCVE_GRYPE_HIGH_FINDINGS) || echo '{}')" \
		webserver python manage.py shell < $(OPENCVE_MK_DIR)opencve_grype_subscribe.py

.PHONY: opencve-superuser
opencve-superuser:
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T -e DJANGO_SUPERUSER_USERNAME=$(OPENCVE_ADMIN_USER) -e DJANGO_SUPERUSER_EMAIL=$(OPENCVE_ADMIN_EMAIL) -e DJANGO_SUPERUSER_PASSWORD=$(OPENCVE_ADMIN_PASS) webserver python manage.py createsuperuser --noinput || true
	$(Q)cd $(OPENCVE_SRC)/docker && docker compose exec -T postgres psql -U opencve -d opencve -c "INSERT INTO account_emailaddress(email, verified, \"primary\", user_id) SELECT email, 1::bool, 1::bool, id FROM opencve_users WHERE username='$(OPENCVE_ADMIN_USER)' ON CONFLICT (user_id, email) DO NOTHING;"
	@echo "==> Admin user ready: $(OPENCVE_ADMIN_USER) / $(OPENCVE_ADMIN_PASS)"

# ── Stop & Remove ──────────────────────────────────────────────────────────────
.PHONY: opencve-rm
opencve-rm:
	$(Q)test -d $(OPENCVE_SRC)/docker && (cd $(OPENCVE_SRC)/docker && docker compose down) || echo "==> No OpenCVE source found under $(OPENCVE_SRC)"
	@echo "==> OpenCVE stopped (volumes preserved)"

.PHONY: opencve-clean
opencve-clean:
	$(Q)test -d $(OPENCVE_SRC)/docker && (cd $(OPENCVE_SRC)/docker && docker compose down -v) || echo "==> No OpenCVE source found under $(OPENCVE_SRC)"
	@rm -rf $(OPENCVE_DIR)
	@echo "==> OpenCVE removed (volumes deleted, source tree removed)"

import os

from django.utils import timezone
from organizations.models import Membership, Organization
from projects.models import Project
from users.models import User

user = User.objects.get(username=os.environ["OPENCVE_SUBSCRIBE_USER"])

org, _ = Organization.objects.get_or_create(name=os.environ["OPENCVE_SUBSCRIBE_ORG"])
Membership.objects.get_or_create(
    user=user,
    organization=org,
    defaults={"role": Membership.OWNER, "date_joined": timezone.now()},
)

project, _ = Project.objects.get_or_create(
    name=os.environ["OPENCVE_SUBSCRIBE_PROJECT"], organization=org
)
vendors = os.environ.get("OPENCVE_SUBSCRIBE_VENDORS", "").split()
project.subscriptions["vendors"] = sorted(set(project.subscriptions["vendors"]) | set(vendors))
project.save()

print(f"==> Project '{project.name}' (org '{org.name}') subscriptions: {project.subscriptions}")

from cves.models import Cve

# {cve_id: [package_name, ...]} for the packages actually found in the scan.
# Merges whatever grype-crit/grype-high cached — either or both may be
# present depending on which was run before this.
crit_findings = json.loads(os.environ.get("OPENCVE_GRYPE_CRIT_FINDINGS", "{}") or "{}")
high_findings = json.loads(os.environ.get("OPENCVE_GRYPE_HIGH_FINDINGS", "{}") or "{}")
findings = {**crit_findings, **high_findings}
cve_ids = sorted(findings)

org = Organization.objects.get(name=os.environ["OPENCVE_SUBSCRIBE_ORG"])
project = Project.objects.get(
    name=os.environ["OPENCVE_SUBSCRIBE_PROJECT"], organization=org
)

found = list(Cve.objects.filter(cve_id__in=cve_ids).values_list("cve_id", "vendors"))
found_ids = {cve_id for cve_id, _ in found}
missing_ids = sorted(set(cve_ids) - found_ids)


def match_tokens(pkg_names):
    # Package manager names (rpm, npm, go modules, ...) don't map 1:1 onto
    # NVD/CPE vendor:product slugs, so this is a best-effort substring match:
    # split each scanned package name into alnum tokens (>=3 chars, to skip
    # noise like version-ish "v5"), then keep a CVE's vendor/product entry
    # only if one of those tokens shows up in it.
    tokens = set()
    for name in pkg_names:
        tokens |= {t for t in re.split(r"[^a-z0-9]+", name.lower()) if len(t) >= 3}
    return tokens


new_vendors = set()
new_products = set()
skipped = set()
for cve_id, vendors in found:
    tokens = match_tokens(findings.get(cve_id, []))
    for entry in vendors:
        if any(tok in entry.lower() for tok in tokens):
            (new_products if "$PRODUCT$" in entry else new_vendors).add(entry)
        else:
            skipped.add(entry)

before_vendors = set(project.subscriptions["vendors"])
before_products = set(project.subscriptions["products"])

project.subscriptions["vendors"] = sorted(before_vendors | new_vendors)
project.subscriptions["products"] = sorted(before_products | new_products)
project.save()

print(
    f"==> CVE IDs given: {len(cve_ids)} | matched in OpenCVE: {len(found_ids)} | not in OpenCVE DB: {len(missing_ids)}"
)
if missing_ids:
    print(f"==> Not found (skipped): {' '.join(missing_ids)}")
print(
    f"==> Unrelated vendor/product entries skipped (didn't match a scanned package name): {len(skipped)}"
)
print(f"==> New vendor subscriptions: {sorted(new_vendors - before_vendors) or 'none'}")
print(f"==> New product subscriptions: {sorted(new_products - before_products) or 'none'}")
print(
    f"==> Project '{project.name}' now subscribes to "
    f"{len(project.subscriptions['vendors'])} vendor(s), "
    f"{len(project.subscriptions['products'])} product(s)"
)
